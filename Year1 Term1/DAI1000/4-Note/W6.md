## 二、Core Part 1: Three Main ML Paradigms (核心部分 1：机器学习的三大核心范式)

ML is divided into three paradigms based on **data type** and **learning mechanism**; each has unique tasks, algorithms, and use cases:

机器学习根据**数据类型**和**学习机制**分为三大范式，各有独特任务、算法与应用场景：

### 1. Supervised Learning (监督学习)

| 维度 (Dimension) | 中文 (Chinese)                                               | English                                                      |
| ---------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 核心特征         | 基于**标注数据**（输入与对应输出绑定）学习，训练后可对新输入预测输出 | Learns from **labeled data** (input-output pairs); predicts outputs for new inputs after training |
| 核心任务         | 1. 回归（Regression）：预测连续值2. 分类（Classification）：将数据划分到离散类别 | 1. Regression: Predict continuous values2. Classification: Categorize data into discrete classes |
| 典型算法         | K 近邻（KNN）、线性模型（Linear Model）、深度神经网络（DNN） | K-Nearest Neighbors (KNN), Linear Models, Deep Neural Networks (DNNs) |

#### （1）Regression (回归任务：预测连续值)

| 中文描述                                         | English Description                                          | 案例 (Example)                                               |
| ------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 因变量为连续值，模型学习输入与连续输出的映射关系 | Dependent variable is continuous; model learns input-continuous output mapping | 1. 房价预测（输入：房间数、面积、位置；输出：预测房价）2. 医疗风险预测（输入：年龄、体重、病史；输出：预测血压） |
| 常用算法                                         | Common Algorithms                                            | 线性回归（Linear Regression）、逻辑回归（Logistic Regression）、多项式回归（Polynomial Regression） |

#### （2）Classification (分类任务：划分离散类别)

| 分类类型 (Type)       | 中文描述                  | English Description                                    | 案例 (Example)                                               |
| --------------------- | ------------------------- | ------------------------------------------------------ | ------------------------------------------------------------ |
| 二分类（Binary）      | 数据划分为 2 个类别       | Categorizes data into 2 classes                        | 垃圾邮件检测（输入：邮件主题 / 正文 / 发件人；输出：垃圾邮件 / 非垃圾邮件）→ 应用：Gmail/Outlook 过滤 |
| 多分类（Multi-class） | 数据划分为 3 个及以上类别 | Categorizes data into 3+ classes                       | 手写数字识别（输入：手写数字像素值；输出：0-9 的数字标签）→ 应用：邮政分拣、银行支票处理 |

### 2. Unsupervised Learning (无监督学习)

| 维度 (Dimension) | 中文 (Chinese)                                               | English                                                      |
| ---------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 核心特征         | 基于**无标注数据**学习，无需人工干预，自动发现数据隐藏模式或分组 | Learns from **unlabeled data**; discovers hidden patterns/groups without human intervention |
| 核心任务         | 1. 聚类（Clustering）：按相似度分组2. 关联规则（Association Rules）：挖掘变量间关联 | 1. Clustering: Group data by similarity2. Association Rules: Mine relationships between variables |
| 典型算法         | K 均值（K-means）、主成分分析（PCA）、生成模型（Generative Model） | K-means, Principal Component Analysis (PCA), Generative Models |

#### （1）Clustering (聚类任务：按相似度分组)

#### （3）Limitations of Unsupervised Learning (无监督学习的局限)

| 中文                                                         | English                                                      |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| 1. 计算复杂度高（大量无标注数据处理困难）2. 训练时间长3. 结果准确率风险高（无标注数据验证）4. 透明度低（聚类依据不明确） | 1. High computational complexity (hard to process large unlabeled data)2. Long training time3. High risk of inaccurate results (no labeled data for validation)4. Low transparency (unclear clustering basis) |

### 3. Reinforcement Learning (强化学习)

| 维度 (Dimension) | 中文 (Chinese)                                               | English                                                      |
| ---------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 核心特征         | 智能体（Agent）在动态环境（Environment）中通过 “试错” 学习，依据环境反馈的**奖励（Reward）** 最大化目标 | Agent learns via "trial and error" in a dynamic environment; maximizes rewards from environmental feedback |
| 核心要素         | 1. 智能体（Agent）：执行动作的主体2. 环境（Environment）：智能体交互的场景3. 状态（State, S）：环境当前情况4. 动作（Action, A）：智能体的行为5. 奖励（Reward, R）：环境对动作的反馈 | 1. Agent: Entity that takes actions2. Environment: Scenario where the agent interacts3. State (S): Current condition of the environment4. Action (A): Behavior of the agent5. Reward (R): Environmental feedback on actions |
| 典型案例         | 1. AlphaGo（智能体：AlphaGo；环境：围棋棋盘；奖励：赢棋）2. 自动驾驶汽车（智能体：自动驾驶车；动作：加速 / 刹车 / 转弯；奖励：安全高效行驶） | 1. AlphaGo (Agent: AlphaGo; Environment: Go board; Reward: Winning the game)2. Self-driving cars (Agent: Self-driving car; Actions: Accelerate/brake/turn; Reward: Safe and efficient driving) |

### 4. Comparison of Three ML Paradigms (三大机器学习范式对比表)

| 对比维度 (Comparison Dimension) | Supervised Learning (监督学习)                 | Unsupervised Learning (无监督学习)          | Reinforcement Learning (强化学习)                 |
| ------------------------------- | ---------------------------------------------- | ------------------------------------------- | ------------------------------------------------- |
| 输入数据 (Input Data)           | 标注数据（Labeled Data）                       | 无标注数据（Unlabeled Data）                | 环境反馈（Environmental Feedback）                |
| 核心目标 (Core Goal)            | 对已知输入预测输出（Predict output for input） | 发现数据内在结构（Discover data structure） | 通过动作最大化奖励（Maximize reward via actions） |
| 典型案例 (Typical Examples)     | 垃圾邮件检测、猫 / 狗分类                      | 客户细分、异常检测                          | 自动驾驶、广告个性化                              |
| 局限性 (Limitations)            | 需大量标注数据、易过拟合                       | 结果难解释、计算复杂度高                    | 训练慢、奖励函数设计难、泛化能力弱                |

## 三、Core Part 2: Deep Learning (核心部分 2：深度学习)

Deep Learning is a **subset of ML** that uses **deep neural networks** (multi-layered neural networks) for learning and prediction.

深度学习是机器学习的**子集**，利用**深度神经网络**（多层神经网络）实现学习与预测。

### 1. Definition & Architecture of Deep Neural Networks (深度神经网络的定义与架构)

| 组件 (Component)        | 中文描述                                                     | English Description                                          |
| ----------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 输入层（Input Layer）   | 接收原始特征数据（如 X₁, X₂, X₃）                            | Receives raw feature data (e.g., X₁, X₂, X₃)                 |
| 隐藏层（Hidden Layers） | 由人工神经元（Nodes）组成，将输入转换为新的特征表示（多层隐藏层是 “深度” 的核心） | Composed of artificial neurons; transforms input into new feature representations (multiple hidden layers = "depth") |
| 输出层（Output Layer）  | 输出最终预测结果（回归任务：连续值；分类任务：概率分布）     | Outputs final predictions (regression: continuous value; classification: probability distribution) |
| 参考视频                | Reference Video                                              | 神经网络科普：https://youtu.be/jmmW0F0biz0                   |

### 2. How Neural Networks Work (神经网络的工作原理)

#### （1）Neuron Calculation Example (神经元计算示例：“是否去派对” 决策)

| 决策问题                     | Should I go to the party tonight? (1=GO, 0=Don’t GO)         |
| ---------------------------- | ------------------------------------------------------------ |
| 输入特征（X）                | 1. X₁：是否有早课（Yes=1, No=0）2. X₂：暗恋对象是否在（Yes=1, No=0）3. X₃：作业是否完成（Yes=0, No=1） |
| 权重（W，特征重要性）        | 1. W₁=-6（重视早课，负向影响）2. W₂=5（暗恋对象是强动机，正向影响）3. W₃=-3（担心未完成作业，负向影响） |
| 偏置（Bias，基线倾向）       | B=+2（天生倾向外出，正向基线）                               |
| 计算公式                     | 加权和 + 偏置：\(\sum W_iX_i + Bias = W_1X_1 + W_2X_2 + W_3X_3 + B\) |
| 实例计算（X₁=0, X₂=1, X₃=1） | \(0 + 5 - 3 + 2 = 4\) → 激活函数输出 1（去派对）             |

#### （2）Key Processes (核心流程)

| 流程 (Process)                  | 中文描述                                                     | English Description                                          |
| ------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 前向传播（Forward Propagation） | 数据从输入层→隐藏层→输出层，逐层计算预测结果                 | Data flows from input layer → hidden layers → output layer; computes predictions layer by layer |
| 反向传播（Backpropagation）     | 利用梯度下降（Gradient Descent）计算预测误差，反向调整各层权重与偏置，最小化损失函数 | Uses gradient descent to calculate prediction errors; adjusts weights/biases backward to minimize loss function |

### 3. Common Deep Learning Architectures (常见深度学习架构)

| 架构 (Architecture) | 中文描述                                       | 适用场景 (Applicable Scenario)                       |
| ------------------- | ---------------------------------------------- | ---------------------------------------------------- |
| 卷积神经网络（CNN） | 含卷积层（过滤图像局部特征），擅长提取空间特征 | 图像处理（图像识别、人脸识别、医疗影像分析）         |
| 循环神经网络（RNN） | 含 “记忆单元”，可处理序列数据（依赖历史信息）  | 时序数据任务（自然语言处理 NLP、语音识别、文本生成） |

### 4. Deep Learning Applications (深度学习的应用场景)

| 应用 (Application)               | 中文描述                                                     | English Description                                          |
| -------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 人脸识别（Face Recognition）     | 自动学习面部像素特征（无需人工定义特征）                     | Automatically learns facial pixel features (no manual feature design) |
| 机器翻译（Language Translation） | 理解上下文语义（如 “bank” 可译为 “银行” 或 “河岸”）          | Understands contextual meaning (e.g., "bank" = financial institution or river bank) |
| 图像识别（Image Recognition）    | 逐层学习特征（早期层：边缘 / 颜色；中期层：耳朵 / 眼睛；深层：完整猫的特征） | Learns features layer by layer (early: edges/colors; middle: ears/eyes; deep: full cat features) |

### 5. Benefits & Limitations of Deep Learning (深度学习的优势与局限)

| 优势（Benefits）                                             | 局限（Limitations）                                          |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| 1. 自动特征学习（无需人工设计特征）2. 擅长非结构化数据（图像、音频、文本）3. 规模适应性强（数据越多，性能越好） | 1. 需大量数据（通常需数千 / 数百万样本）2. 黑箱问题（决策过程难以解释）3. 易过拟合（学习数据噪声而非真实模式）4. 潜在偏见（模型可能继承数据偏见，导致不公平预测） |
