## 五、Core Concept 3: Working Principles of Generative AI (核心概念 3：生成式 AI 的工作原理)

Generative AI follows three core stages: **Training → Tuning → Generation/Evaluation/Retuning**

生成式 AI 遵循三大核心阶段：**训练 → 调优 → 生成 / 评估 / 再调优**

### 1. Three Core Stages (三大核心阶段)

| 阶段 (Stage)                                          | 中文描述                                                     | English Description                                          |
| ----------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| Training (训练)                                       | 基于海量数据训练 “基础模型”（Foundation Model），使其学习数据中的模式与关联，作为多类生成应用的基础 | Train a "Foundation Model" on massive data to learn patterns/relationships; serve as the basis for multiple generative applications |
| Tuning (调优)                                         | 将基础模型适配到特定应用场景（如将通用文本模型调优为法律文档生成模型） | Tailor the foundation model to specific scenarios (e.g., adapt a general text model to legal document generation) |
| Generation/Evaluation/Retuning (生成 / 评估 / 再调优) | 生成内容→评估输出质量→持续调整模型参数，提升准确性与相关性   | Generate content → evaluate output quality → continuously adjust model parameters to improve accuracy and relevance |

### 2. Key Technical Mechanisms (关键技术机制)

#### （1）Autoregressive Generation (自回归生成：“文字接龙”)

| 中文描述                                                     | English Description                                          | 示例 (Example)                                               |
| ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 核心策略：每次仅生成一个输出单元（Token，如单词 / 字符），前一个输出作为下一个生成的输入，逐步完成完整内容 | Core Strategy: Generate one output unit (Token, e.g., word/character) at a time; use the previous output as input for the next generation to build complete content | 输入 “The Chinese University of” → 生成 “hong” → 输入 “The Chinese University of hong” → 生成 “kong” → 最终输出 “The Chinese University of Hong Kong” |

#### （2）Transformer Architecture (Transformer 架构：生成式 AI 的核心框架)

| 核心特性 (Core Feature)               | 中文描述                                                     | English Description                                          |
| ------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| Attention Mechanism (注意力机制)      | 模型处理信息时，聚焦输入中最相关的部分（如生成 “银行” 时，关注上下文判断是 “金融银行” 还是 “河岸”） | The model focuses on the most relevant parts of the input when processing information (e.g., judge "bank" as "financial institution" or "river bank" based on context) |
| Parallel Processing (并行处理)        | 同时处理所有 Token，而非逐次处理，大幅提升训练效率           | Processes all Tokens simultaneously (not one by one), significantly improving training efficiency |
| Contextual Understanding (上下文理解) | 动态捕捉序列中 Token 的依赖关系，使每个 Token 的含义融入整体语境 | Dynamically captures dependencies between Tokens in a sequence, integrating each Token’s meaning into the overall context |
| 参考视频                              | Reference Video                                              | https://www.bilibili.com/video/BV14Ushz7Eo8/                 |

#### （3）Controlled Randomness (可控随机性：输出多样性的关键)

生成式 AI 并非固定输出，而是通过 “采样方法” 和 “温度参数” 控制随机性，平衡稳定性与创造性：

| 控制方式 (Control Method)   | 中文描述                                                     | English Description                                          |
| --------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 采样方法 (Sampling Methods) | 1. 贪心解码（Greedy Decoding）：始终选概率最高的下一个 Token（稳定但单调）；2. Top-k 采样：仅从概率前 k 的 Token 中随机选择（控制输出范围） | 1. Greedy Decoding: Always select the Token with the highest probability (stable but monotonous); 2. Top-k Sampling: Randomly select from the top k most probable Tokens (controls output range) |
| 温度参数 (Temperature)      | - 低温（T<1）：扩大概率差异，高概率 Token 更易被选（结果确定、保守）；- 高温（T>1）：平滑概率分布，低概率 Token 更易被选（结果多样、有创造性） | - Low T (<1): Amplifies probability differences (certain, conservative results); - High T (>1): Smoothes probability distribution (diverse, creative results) |
| 可视化工具                  | Visualization Tool                                           | https://poloclub.github.io/transformerexplainer/             |

#### （4）AI Image Generation: Diffusion Model (AI 图像生成：扩散模型)

| 中文描述                                                     | English Description                                          | 参考视频 (Reference Video)                                   |
| ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 核心原理：通过 “逐步去噪” 生成图像 —— 先从随机噪声开始，反复调整像素，逐步逼近提示词描述的目标图像 | Core Principle: Generate images via "step-by-step denoising" — start with random noise, adjust pixels repeatedly, and gradually approach the target image described in the prompt | 1. https://www.bilibili.com/video/BV12m421g7Bx2. https://www.bilibili.com/video/BV1U1shzJEYf/ |

## 六、Key Questions About Generative AI (生成式 AI 的关键问题解析)

### 1. Is Generative AI “Truly Thinking” When It Shows Reasoning? (生成式 AI 的 “推理” 是真思考吗？)

| 中文结论                                                     | English Conclusion                                           |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| 不是真思考，而是 “模拟推理”（Simulated Reasoning）：1. 生成式 AI 通过学习海量文本中 “推理的表达方式”（如 “步骤 1… 因此… 所以…”），模仿人类推理的文字形式；2. 本质是基于数据模式预测下一个 Token，而非理解逻辑关系，类似 “演员念剧本”，无真实认知 | No — it is "simulated reasoning":1. Generative AI imitates the "form of human reasoning" (e.g., "Step 1… therefore… thus…") by learning patterns in massive text;2. Essentially predicts the next Token based on data patterns, not understanding logical relationships — like an "actor reciting a script" with no real cognition |

### 2. Why Does Generative AI “Make Things Up” (Hallucination)? (生成式 AI 为何 “编造信息”（幻觉）？)

| 中文原因                                                     | English Reason                                               |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| 1. 生成逻辑：基于 “预测下一个 Token” 生成内容，而非查询事实库，目标是 “流畅相关” 而非 “真实准确”；2. 高频场景：- 询问罕见 / 特定事实（训练数据中无相关信息，只能猜测）；- 需表现 “有用 / 权威”（生成 “听起来合理” 的内容）；- 无实时数据库访问权限（除非连接 Bing 等工具）；3. 关键澄清：既非 “推理” 也非 “说谎”，而是遵循数学模式预测，无真假判断能力或欺骗意图 | 1. Generation Logic: Creates content by "predicting the next Token", not querying a fact database — goal is "fluency/relevance" not "truth/accuracy";2. High-Frequency Scenarios:- Asking about rare/specific facts (no relevant training data, so it guesses);- Needing to seem "helpful/authoritative" (generates "plausible-sounding content");- No real-time database access (unless connected to tools like Bing);3. Key Clarification: Neither "reasoning" nor "lying" — it follows mathematical patterns to predict, with no ability to judge truth/falsity or intent to deceive |

## 七、Generative AI Optimization Methods (生成式 AI 的优化方法)

### 1. Fine-Tuning (微调)

| 中文描述                                                     | English Description                                          | 优势 (Benefits)                                              |                                                              |
| ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 以预训练基础模型为起点，用**小规模任务专属数据集**进一步训练，适配特定场景 | Start with a pre-trained foundation model; further train it with a **small task-specific dataset** to adapt to specific scenarios | 1. 领域适配（如将通用模型调优为法律 / 医疗专用模型）；2. 提升特定任务性能（如情感分析、问答）；3. 数据需求低（无需从头训练，节省算力与时间）；4. 快速部署（缩短 AI 系统开发周期） |                                                              |
| 示例 (Example)                                               | Example                                                      | 调整图像生成模型的插画风格；用企业私有数据补充模型知识       | Adjust the illustration style of an image generation model; supplement the model’s knowledge with enterprise private data |

### 2. Retrieval-Augmented Generation (RAG：检索增强生成)

| 中文描述                                                     | English Description                                          | 核心流程 (Core Process)                                      |
| ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 将模型连接到**权威知识库 / 搜索工具**，生成内容前先检索外部事实，避免幻觉，提升准确性 | Connect the model to **authoritative knowledge bases/search tools**; retrieve external facts before generating content to avoid hallucinations and improve accuracy | 1. 接收用户查询（Query）；2. 检索相关知识（从权威来源获取信息）；3. 增强提示词（将检索到的信息融入 Prompt）；4. 模型基于增强提示词生成输出 |

## 八、How to Collaborate Effectively with Generative AI (如何与生成式 AI 高效协作)

| 协作方法 (Collaboration Method) | 中文建议                                                     | English Suggestion                                           |
| ------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 1. 选择合适工具                 | 根据任务选专用工具：写作（ChatGPT/DeepSeek）、图像（DALL・E/Midjourney）、代码（GitHub Copilot）、学术搜索（Elicit/Perplexity） | Choose task-specific tools: Writing (ChatGPT/DeepSeek), Image (DALL·E/Midjourney), Code (GitHub Copilot), Academic Search (Elicit/Perplexity) |
| 2. 明确表达需求                 | 包含任务目标、背景信息，尽可能提供示例（如 “按以下格式写报告：1. 引言…2. 方法…”） | Include task goals, background info, and provide examples if possible (e.g., "Write the report in this format: 1. Introduction… 2. Methods…") |
| 3. 拆分复杂任务                 | 将大任务拆分为小步骤，可让 AI 协助规划（如 “帮我把报告拆为 3 部分”） | Split complex tasks into small steps; ask AI to help plan (e.g., "Help me divide this report into 3 parts") |
| 4. 引导思考过程                 | 要求 AI “逐步分析”（如 “一步步思考如何写 grant proposal”），提升输出逻辑性 | Ask AI to "think step by step" (e.g., "Think through how to write a grant proposal step by step") to improve output logic |
| 5. 优化提示词                   | 若不知如何提问，让 AI 协助优化（如 “帮我写一个更好的 Prompt 来实现 X 目标”） | If unsure how to ask, let AI help optimize the prompt (e.g., "Help me write a better prompt to achieve goal X") |
| 6. 验证信息准确性               | 要求 AI 提供来源，并自行核查（警惕 AI 幻觉，不盲目信任）     | Ask AI to provide sources and verify them yourself (be alert to hallucinations; do not trust blindly) |
