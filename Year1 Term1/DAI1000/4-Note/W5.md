## 二、Core Concept 1: Definition & Scope of Machine Learning (核心概念 1：机器学习的定义与范畴)

### 1. ML Definition (机器学习定义)

| 中文                                                         | English                                                      |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| 机器学习是计算机从数据中学习并做出预测，无需人工显式编程的技术 | Machine Learning (ML) enables computers to learn from data and make predictions **without being explicitly programmed** |
| 核心逻辑：从训练数据中寻找函数 \(f(x)\)，实现输入 x 到输出 y 的映射（例：线性函数 \(y=ax+b\) 中，通过数据学习 a 和 b 的值） | Core Logic: Find a function \(f(x)\) from training data to map input x to output y (e.g., learn a and b in linear function \(y=ax+b\) via data) |

### 2. Key Processes of ML (机器学习的关键流程)

| 流程 (Process)   | 中文描述                                                     | English Description                                          |
| ---------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| Learning (学习)  | 向机器输入数据（文本、图像、传感器信号等），通过算法提取数据中的模式 | Feed data (text, images, sensor signals) to the machine; extract patterns via algorithms |
| Inference (推理) | 模型训练完成后，输入新数据，输出预测结果（分类 / 回归等）    | After training, input new data and output prediction results (classification/regression) |

### 3. ML Classification & Technical Examples (机器学习分类与技术案例)

#### （1）ML Paradigm Classification (机器学习范式分类)

| 范式 (Paradigm)          | 中文                            | English                              |
| ------------------------ | ------------------------------- | ------------------------------------ |
| Supervised Learning      | 监督学习（需标注数据）          | Learning with labeled data           |
| Unsupervised Learning    | 无监督学习（无需标注数据）      | Learning without labeled data        |
| Semi-Supervised Learning | 半监督学习（部分标注数据）      | Learning with partially labeled data |
| Self-Supervised Learning | 自监督学习（数据自生成标注）    | Learning with self-generated labels  |
| Reinforcement Learning   | 强化学习（通过奖励 / 惩罚学习） | Learning via rewards/punishments     |
| Deep Learning            | 深度学习（基于深度神经网络）    | Learning via deep neural networks    |

#### （2）ML Technique & Input-Output Cases (机器学习技术与输入输出案例)

| 技术 (Technique)            | 输入数据 (Input Data)              | 输出结果 (Output Result)         | 应用场景 (Application Scenario)                |
| --------------------------- | ---------------------------------- | -------------------------------- | ---------------------------------------------- |
| Regression (回归)           | 股票数据、房屋特征（面积、房间数） | 股票价格预测、房屋价格估算       | Stock Price Prediction, House Price Estimation |
| Classification (分类)       | 邮件文本、图像（猫 / 狗）          | 垃圾邮件识别、图像类别标注       | Spam Detection, Image Labeling (Cat/Dog)       |
| Clustering (聚类)           | 客户交易数据                       | 市场细分（客户群体划分）         | Market Segmentation                            |
| Association Rule (关联规则) | 购物篮数据                         | 推荐系统（如 “购买 A 则推荐 B”） | Recommendation Systems                         |

## 三、Core Concept 2: Key Steps in Machine Learning (核心概念 2：机器学习的关键步骤)

ML follows 4 core stages: **Prepare Dataset → Design Model → Identify Key Values → Evaluate Model**

机器学习遵循 4 个核心阶段：**数据准备 → 模型设计 → 关键值确定 → 模型评估**

### Stage 0: Prepare the Dataset (阶段 0：数据准备)

The foundation of ML; data must be converted into numerical form for algorithm processing

机器学习的基础；数据需转换为数值形式才能被算法处理

#### 1. Data Types & Numerical Conversion (数据类型与数值转换)

| 数据类型 (Data Type)        | 转换方式 (Conversion Method)                | 示例 (Example)                                               |
| --------------------------- | ------------------------------------------- | ------------------------------------------------------------ |
| Images (图像)               | 转换为像素强度值（如 RGB 通道数值）         | 一张猫的图像 → 像素矩阵（如 \(\begin{bmatrix}170&238&85\\68&136&17\end{bmatrix}\)） |
| Text (文本)                 | 分词（Tokenization）→ 向量嵌入（Embedding） | 句子 “The mouse ran up” → 分词后 [The, mouse, ran, up] → 向量 [0.006,0.652,0.270,-0.556] |
| Numerical Tables (数值表格) | 直接使用（或标准化格式）                    | 房屋数据表格（面积：100㎡，房间数：3 → 数值 [100,3]）        |
| Audio/Video (音频 / 视频)   | 音频转频谱图数值，视频转帧图像像素值        | 语音指令 → 频谱图数值矩阵；监控视频 → 每帧图像的像素数据     |

#### 2. Data Preparation Process (数据准备流程)

| 步骤 (Step)     | 中文描述                                                     | English Description                                          |
| --------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| Data Collection | 从多来源收集大量相关数据                                     | Gather large amounts of relevant data from multiple sources  |
| Data Cleaning   | 1. 去除重复数据；2. 标准化格式（修正格式不一致）；3. 处理缺失值（均值 / 众数填充、删除、预测模型补全） | 1. Remove duplicates; 2. Standardize formats (fix inconsistencies); 3. Handle missing values (mean/mode imputation, deletion, predictive filling) |
| Data Annotation | 为数据添加标签（尤其监督学习），需人工标注（如医生标注医疗影像诊断结果），耗时且成本高 | Add labels to data (especially for supervised learning); requires manual annotation (e.g., doctors label medical images); time-consuming and costly |

#### 3. Data Splitting (数据划分)

| 数据集 (Dataset)        | 中文用途                                           | English Purpose                                              | 占比参考 (Reference Proportion) |
| ----------------------- | -------------------------------------------------- | ------------------------------------------------------------ | ------------------------------- |
| Training Set (训练集)   | 训练模型，让模型学习数据模式并优化内部参数         | Train the model to learn patterns and optimize internal parameters | 60%-80%                         |
| Validation Set (验证集) | 调优超参数、选择最佳模型配置，避免模型过拟合训练集 | Tune hyperparameters, select optimal model configuration; prevent overfitting to training set | 10%-20%                         |
| Test Set (测试集)       | 评估训练完成的模型，测试模型对新数据的泛化能力     | Evaluate the fully trained model; test generalization to new data | 10%-20%                         |

#### 4. Real-World Data Preparation Examples (真实数据准备案例)

| 任务 (Task)                                           | 数据集 (Dataset)                                  | 标签 (Label)                                    | 挑战 (Challenge)                |
| ----------------------------------------------------- | ------------------------------------------------- | ----------------------------------------------- | ------------------------------- |
| COVID-19 Chest Scan Classification (新冠胸部扫描分类) | 公开医疗胸部 X 光数据集（分训练 / 验证 / 测试集） | 医生提供的诊断结果（新冠阳性 / 阴性）           | 医疗数据隐私保护                |
| 3D Street Scene Annotation (3D 街景标注)              | 3D 城市环境图像序列                               | 人工标注像素级 / 边界框标签（汽车、树木、路标） | 标注工作量极大（多帧 + 多类别） |

### Stage 1: Design the Model (阶段 1：模型设计)

Define model architecture based on tasks; model type determines how to map input to output

根据任务定义模型架构；模型类型决定输入到输出的映射方式

#### Common Models & Applications (常见模型与应用)

| 模型 (Model)                        | 中文描述                        | English Description                                     | 典型用途 (Typical Uses)                                      |
| ----------------------------------- | ------------------------------- | ------------------------------------------------------- | ------------------------------------------------------------ |
| Linear Regression (线性回归)        | 拟合直线以预测连续值            | Fit a straight line to predict continuous values        | 房屋价格预测、收入预测（House Price Prediction, Income Forecasting） |
| Logistic Regression (逻辑回归)      | 预测二分类概率（如 0/1）        | Predict binary classification probabilities (e.g., 0/1) | 疾病诊断、购买意愿预测（Disease Diagnosis, Purchase Prediction） |
| KNN (K-Nearest Neighbors, K 最近邻) | 参考 K 个邻近样本的标签进行预测 | Predict via labels of K nearby samples                  | 图像分类、推荐系统（Image Classification, Recommendation Systems） |

#### Example: Linear Regression for Car MPG Prediction (案例：汽车油耗预测的线性回归)

- **Input (输入)**: 汽车重量（单位：1000 磅，Feature）
- **Output (输出)**: 每加仑英里数（MPG，Label）
- **Model Formula (模型公式)**: \(y=mx+b\)（\(y=MPG\)，\(x=重量\)，\(m=斜率\)，\(b=y轴截距\)）
- **Goal (目标)**: 找到最优 m 和 b，使直线尽可能贴合数据点

### Stage 2: Identify the Key Values (阶段 2：关键值确定)

Train the model to learn **parameters** (model-calculated) and set **hyperparameters** (human-controlled)

训练模型以学习**参数**（模型计算得出），并设置**超参数**（人工控制）

#### 1. Parameters (参数：模型训练中计算的数值)

| 定义 (Definition)                              | 示例 (Example)                                               | 目标 (Goal)                                       |
| ---------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------- |
| 模型内部可优化的变量，决定输入到输出的映射关系 | 线性回归 \(y=b+w_1x_1+w_2x_2\) 中的 b（偏置）、\(w_1\)（特征 1 权重）、\(w_2\)（特征 2 权重） | 找到使**损失函数（Loss Function）最小化**的参数值 |

#### 2. Loss Function (损失函数：衡量预测误差的指标)

| 指标 (Metric)                      | 中文定义                                                     | 公式 (Formula)                                   | 适用场景 (Applicable Scenario)   |
| ---------------------------------- | ------------------------------------------------------------ | ------------------------------------------------ | -------------------------------- |
| Mean Squared Error (MSE，均方误差) | 计算预测值 \(\hat{y}_i\) 与真实值 \(y_i\) 差值的平方的平均值，误差越大，MSE 越大 | \(MSE=\frac{1}{n}\sum_{i=1}^n(y_i-\hat{y}_i)^2\) | 回归任务（如房价预测、油耗预测） |

#### 3. Optimization Method: Gradient Descent (优化方法：梯度下降)

| 中文描述                                                     | English Description                                          | 核心步骤                                                     |
| ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 一种迭代优化算法，通过不断调整参数，逐步减小损失函数值，最终找到最优参数 | An iterative optimization algorithm that adjusts parameters continuously to reduce loss, eventually finding optimal parameters | 1. 计算当前参数的损失值；2. 确定使损失减小的参数调整方向；3. 沿该方向小幅调整参数；4. 重复步骤 1-3，直到损失无法进一步减小 |
| 参考视频                                                     | Reference Video                                              | https://www.bilibili.com/video/BV1HBJ9zRE6N/                 |

#### 4. Hyperparameters (超参数：人工设置的数值)

| 超参数 (Hyperparameter) | 中文定义                         | English Definition                                           | 影响 (Impact)                              |
| ----------------------- | -------------------------------- | ------------------------------------------------------------ | ------------------------------------------ |
| Learning Rate (学习率)  | 控制参数调整的步长，浮点型数值   | Controls the step size of parameter updates (floating-point number) | 过小时：模型收敛慢；过大时：可能错过最优解 |
| Batch Size (批大小)     | 模型更新参数前处理的数据样本数量 | Number of samples processed before updating parameters       | 过小时：训练效率低；过大时：占用内存多     |
| Epochs (轮次)           | 模型完整遍历训练集的次数         | Number of times the model fully processes the training set   | 过少：模型欠拟合；过多：可能过拟合         |

**Example (示例)**: 训练集含 1000 个样本，批大小 = 100 → 1 个轮次（Epoch）需 10 次迭代（Iteration）完成训练

### Stage 3: Evaluate the Model (阶段 3：模型评估)

Assess the model’s generalization ability (performance on new data), not just training loss

评估模型的泛化能力（对新数据的性能），而非仅关注训练损失

#### 1. Evaluation Methods (评估方法)

| 方法 (Method)                           | 中文描述                                                     | English Description                                          |
| --------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| Use Test Set (使用测试集)               | 用未参与训练的测试集评估模型，避免 “用训练数据评估训练效果” 的偏差 | Evaluate with test set (not used in training) to avoid bias of "evaluating training with training data" |
| Apply Evaluation Metrics (应用评估指标) | 回归任务常用指标：MAE（平均绝对误差）、MSE（均方误差）、R²（决定系数） | Common metrics for regression: MAE (Mean Absolute Error), MSE (Mean Squared Error), R² (R-squared) |

#### 2. Key Issue: Overfitting (关键问题：过拟合)

| 中文定义                                                     | English Definition                                           | 示例 (Example)                                               |
| ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 模型在训练集上损失低（性能好），但在测试集上损失高（性能差），无法泛化到新数据 | The model has low loss (good performance) on training set but high loss (poor performance) on test set; fails to generalize to new data | 房价预测模型：训练集 MSE=5000，测试集 MSE=50000 → 模型仅 “死记” 训练数据，无法预测新房屋价格 |
